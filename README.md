# Noita AI

Эксперимент по обучению агента, который управляет ведьмочкой в Noita.

- **Соло.** Научиться доходить до арены Колмисильмя на разных сидах. Измерять долю успешных забегов, время и оставшееся HP.
- **Кооп.** Играть вместе с ИИ-персонажем в Entangled Worlds. Персонаж ставит цели через MCP, а обученная политика управляет его ведьмочкой.

Сейчас в репозитории описан проект. Мод, окружение и обучение ещё предстоит реализовать.

Первый эксперимент — перелететь разрыв и добраться до портала. Сначала проверим этот маршрут скриптом и измерим скорость сброса, затем обучим PPO и сравним результаты на отложенных вариантах маршрута.
